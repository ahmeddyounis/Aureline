# Generated-artifact Project Doctor findings

The canonical generated-artifact Doctor packet is implemented in
[`crates/aureline-support/src/generated_doctor.rs`](../../crates/aureline-support/src/generated_doctor.rs)
and serialized to
[`generated-doctor-packet.json`](./generated-doctor-packet.json).

It is the checked-in truth source for:

- the reviewer and help contract in
  [`docs/generated/generated-doctor.md`](../../docs/generated/generated-doctor.md)
- the boundary schema at
  [`schemas/generated/generated-doctor.schema.json`](../../schemas/generated/generated-doctor.schema.json)
- fixture replay in
  [`crates/aureline-support/tests/generated_doctor.rs`](../../crates/aureline-support/tests/generated_doctor.rs)
- the fixture corpus under
  [`fixtures/generated/doctor/`](../../fixtures/generated/doctor/)

## What the packet models

The packet folds the canonical write-boundary decision packet from
`aureline-generated` into one Project Doctor finding per **degraded**
generated-artifact case. Healthy in-sync own-source cases and cases admitted
through a recorded reviewed override produce no finding. Each finding is
classified into exactly one root-cause state using the frozen resolution
ordering — `source_missing`, then `generator_unavailable`, then
`regeneration_blocked`, then `drift_detected`, then `direct_edit_denied`.

The Support Center Doctor module, the headless `doctor` output, the in-product
help, the About diagnostics excerpt, and the support export all bind to this one
packet and narrow with it. None of them flatten a generated-artifact issue into
a generic save or index failure.

## Traceback and redaction

Each finding traces back to its canonical source (or an explicit
`source_missing` state), its generator identity, and its last checkpoint, so an
operator can follow a generated-artifact issue to its origin. The support export
that wraps this packet is metadata-safe: it preserves that canonical-source and
checkpoint lineage while excluding raw generated bytes, raw diffs, private source
material, and ambient authority or credentials.

## Regenerating this packet

```bash
cargo run -p aureline-support --example dump_generated_doctor -- write
```
