- command-versus-dictation mode separation lost → `mode_separation_unverified`

- hosted/enterprise provider locality undisclosed → `provider_locality_undisclosed`
- transcript/audio retention unbounded for a full claim → `transcript_retention_unbounded`
- command/undo/policy parity incomplete → `command_parity_incomplete`
- keyboard fallback missing → `keyboard_fallback_missing`
- provider unavailable / capture blocked → `provider_unavailable_downgraded`
- verification proof stale or window elapsed → `stale_verification_proof`

- imported/local proof mismatch → `imported_proof_on_local_profile`
