# Saved-query governance and retention fixtures

- `packet.json`: canonical saved-query governance matrix. Four governed rows
  realize the four privacy classes (local-only-private, workspace-shared-redacted,
  support-export-redacted, policy-withheld), each binding a `SavedQuery`, its
  captured `ScopePackBinding`, and a local `QueryHistoryEntry` with a
  captured-vs-current scope drift disclosure. Three signed deep links realize the
  three signature schemes (local content digest, workspace-signed digest,
  policy-signed digest), each with a verifiable content signature, a disclosed
  intent and completeness note, and a supportable return path. The
  local-versus-synced retention matrix governs all five data classes and realizes
  the full sync, retention, and redaction vocabulary. Only the local-only-private
  row keeps a raw query literal, confined to local-only storage; every other
  artifact is hash-only or metadata-only.
- `redacted_export.json`: the support/sync export copy where the local-only
  literal is removed and its query text mode drops to `hash_only`, while hashes,
  scope metadata, captured-vs-current scope truth, the retention matrix, and the
  signed deep links are preserved unchanged.

Each fixture is regenerated by
`crates/aureline-search/examples/dump_saved_query_governance_packet.rs` and
replayed against the seeded matrix by the inline tests in
`crates/aureline-search/src/saved_query_governance/tests.rs`.

Regenerate:

```bash
cargo run -p aureline-search --example dump_saved_query_governance_packet -- canonical \
  > fixtures/search/m5/saved-query-retention/packet.json
cargo run -p aureline-search --example dump_saved_query_governance_packet -- redacted \
  > fixtures/search/m5/saved-query-retention/redacted_export.json
```
