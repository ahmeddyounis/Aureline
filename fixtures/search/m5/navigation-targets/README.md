# Search action-binding and navigation-target fixtures

- `packet.json`: canonical action-binding matrix. Each of the five claimed flows
  (search results, docs results, graph-backed results, history/back-forward
  replay, support handoff replay) binds preview, open-in-place, split, peek, and
  external-handoff actions to canonical result refs and navigation relation
  kinds. Each binding embeds the canonical `SearchActionBinding` verbatim and
  keeps a return anchor distinct from the open target. The matrix realizes the
  five action kinds, the seven covered relation kinds (definition, declaration,
  implementation, reference, type, call, doc-link), and the five fallback
  triggers (none, scope_narrowed, trust_policy, freshness_stale, target_missing).
  A definition-to-declaration degrade and a local-to-browser docs handoff are
  both explicit, recoverable `WrongTargetFallback` rows with a visible reason.
  Sessions are referenced hash-only and the packet is metadata-only.
- `scope_trust_narrowed.json`: degraded matrix where scope, trust, and freshness
  narrow further, so a search-results action that was previously direct now takes
  an explicit, recoverable fallback (strictly more fallbacks than the canonical
  packet), while the action-kind, relation-kind, and fallback-trigger vocabulary,
  the result identity, and the reused binding objects are preserved unchanged.
  History/back-forward replay reads local material and stays unchanged.

Each fixture is regenerated by
`crates/aureline-search/examples/dump_search_action_binding_packet.rs` and
replayed against the seeded matrix by the inline tests in
`crates/aureline-search/src/action_bindings/tests.rs`.

Regenerate:

```bash
cargo run -p aureline-search --example dump_search_action_binding_packet -- canonical \
  > fixtures/search/m5/navigation-targets/packet.json
cargo run -p aureline-search --example dump_search_action_binding_packet -- scope_trust_narrowed \
  > fixtures/search/m5/navigation-targets/scope_trust_narrowed.json
```
