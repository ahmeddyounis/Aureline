# Search export packet, redaction, replay, and consent fixtures

- `packet.json`: canonical search-export governance matrix. Four governed rows
  realize the four export classes (local replay, support bundle, incident packet,
  managed analytics) and the full packet redaction-state vocabulary (raw query
  local-only, query hash only, query material omitted by policy). Each row embeds
  the canonical `SearchExportPacket` verbatim — its query-session ref, selected
  and included result refs, loaded/hidden counts, redaction mode, snapshot truth,
  and evidence refs — alongside the literal-query consent gate and the
  replay-safety disclosure. Only the local-replay row retains a literal query
  string, confined to the device and gated behind explicit
  `query_text_elevated` consent; the support bundle and incident packet are
  hash-only, and managed analytics carries no query material at all. Every packet
  is a captured snapshot (the incident row a disclosed scope drift) that never
  claims live current results.
- `redacted_export.json`: the support/incident export copy where the local-only
  literal is removed and its query-text mode drops to `hash_only`, while hashes,
  scope metadata, result refs, counts, omission disclosure, and the replay-safety
  truth are preserved unchanged.

Each fixture is regenerated by
`crates/aureline-search/examples/dump_search_export_governance_packet.rs` and
replayed against the seeded matrix by the inline tests in
`crates/aureline-search/src/search_export_governance/tests.rs`.

Regenerate:

```bash
cargo run -p aureline-search --example dump_search_export_governance_packet -- canonical \
  > fixtures/search/m5/support-export/packet.json
cargo run -p aureline-search --example dump_search_export_governance_packet -- redacted \
  > fixtures/search/m5/support-export/redacted_export.json
```
