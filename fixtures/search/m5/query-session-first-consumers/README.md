# Durable query-session and result-identity first-consumers fixtures

- `packet.json`: canonical substrate. One hash-only durable query session is
  minted per search surface (quick open, symbol search, full-text search,
  references, docs search, recent navigation) and bound to materialized result
  identities. Every row carries a durable, surface-independent result id, full
  source-stratum dedupe lineage, a structured ranking reason, and an explicit
  action binding, and is stable across row virtualization, preview-pane toggles,
  reason-chip toggles, and pane restore. The same file and symbol identities are
  reused across surfaces (`cross_surface_reuse`), and the four first consumers
  (desktop, CLI/headless inspect, AI context assembly, support export) reuse the
  same session and result ids verbatim.
- `partial_index_stale.json`: degraded substrate where the live index is
  partial/stale, so every live-retrieval surface narrows to a `partial_index`
  freshness and fact label and keeps a partiality note, while result identity and
  source-stratum lineage are preserved unchanged and recent navigation (local
  history) stays `live`.

Each fixture is regenerated by
`crates/aureline-search/examples/dump_query_session_first_consumers_packet.rs`
and replayed against the seeded substrate by the inline tests in
`crates/aureline-search/src/query_session_first_consumers/tests.rs`.

Regenerate:

```bash
cargo run -p aureline-search --example dump_query_session_first_consumers_packet -- canonical \
  > fixtures/search/m5/query-session-first-consumers/packet.json
cargo run -p aureline-search --example dump_query_session_first_consumers_packet -- partial_index_stale \
  > fixtures/search/m5/query-session-first-consumers/partial_index_stale.json
```
