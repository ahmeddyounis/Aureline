# Navigation-continuity fixtures

- `packet.json`: canonical navigation-continuity matrix. Each of the six surfaces
  (editor, diff, notebook, docs, search, graph) binds breadcrumb, outline,
  bookmark, recent-location, back/forward, and peek artifacts to canonical
  anchors. The matrix realizes the five artifact kinds, the six drift states
  (bound, remapped, drifted, missing_target, scope_unavailable, archived), and
  the three history roles (back, forward, recent). Bookmarks bind to canonical
  anchors first and remap only through stable evidence; every drifted, missing,
  scope-unavailable, or archived artifact keeps a visible reason and recovery
  choices and carries no resolved target. The restore projection preserves the
  non-resolving artifacts with reasons. Result-bearing surfaces bind to durable
  result URNs; sessions are referenced hash-only and the packet is metadata-only.
- `workset_drift.json`: degraded matrix where the active workset narrows further,
  so a search bookmark that was previously bound now drifts visibly (strictly
  more unresolved artifacts than the canonical packet), while the surface,
  artifact-kind, and drift-state vocabulary, the artifact identities, and the
  reused continuity objects are preserved unchanged. The drifted bookmark
  survives restore with a visible reason and is never relocated to a nearby
  in-scope result.

Each fixture is regenerated by
`crates/aureline-search/examples/dump_navigation_continuity_packet.rs` and
replayed against the seeded matrix by the inline tests in
`crates/aureline-search/src/navigation_continuity/tests.rs`.

Regenerate:

```bash
cargo run -p aureline-search --example dump_navigation_continuity_packet -- canonical \
  > fixtures/search/m5/navigation-continuity/packet.json
cargo run -p aureline-search --example dump_navigation_continuity_packet -- workset_drift \
  > fixtures/search/m5/navigation-continuity/workset_drift.json
```
