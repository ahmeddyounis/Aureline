# M5 search/navigation qualification fixtures

- `packet.json`: canonical qualification index freezing the M5 search-query,
  result-identity, ranking-reason, and saved-query/privacy matrix. Every claimed
  search surface (quick open, file search, symbol search, docs search,
  graph-backed search, AI context retrieval, saved-query reopen, search export)
  references the one shared query-session and result-identity model, binds the
  canonical contract objects to their own lane proof, and expresses the closed
  result-state vocabulary across the product and CLI/headless deployment modes.
  Every row is `qualified`.
- `partial_index_stale_scope_limited.json`: degraded packet where the index is
  partial/stale, so every live-retrieval surface narrows to `scope_limited` and
  keeps the partial-index/stale state visible; the durable-artifact surfaces
  (saved-query reopen and search export) replay their own captured freshness and
  stay `qualified`.
- `unconsented_query_text_local_only.json`: degraded packet where consent for
  syncing or exporting query material is missing, so the saved-query reopen and
  search export surfaces narrow to `local_query_text_only`; raw query text stays
  local-only and first-class while the sync and export paths are held to
  hash-only or omitted.

Each fixture is regenerated by
`crates/aureline-search/examples/dump_m5_search_navigation_qualification_packet.rs`
and replayed against the seeded packet by the inline tests in
`crates/aureline-search/src/m5_search_navigation_qualification/tests.rs`.
