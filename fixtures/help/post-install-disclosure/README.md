# Post-install disclosure panel fixtures

These fixtures are narrowed `post_install_disclosure_record` panels emitted by the
M5 help-lane producer `aureline_shell::m5_post_install_disclosure`. Each conforms
to [`/schemas/governance/post_install_disclosure.schema.json`](../../../schemas/governance/post_install_disclosure.schema.json)
and is regenerated by the headless emitter
`aureline_shell_m5_post_install_disclosure`. They show a disclosure narrowing
without hiding the object — see
[`/docs/help/m5_post_install_disclosure_panels_contract.md`](../../../docs/help/m5_post_install_disclosure_panels_contract.md).

| Fixture | Demonstrates |
|---|---|
| [`product_build_signature_revoked.json`](./product_build_signature_revoked.json) | An official desktop build whose signing key was revoked after install: signature `signature_revoked`, revocation `revoked_or_yanked` with expired freshness, and a visible revocation row. It no longer reads as verified. |
| [`generated_export_sbom_not_provided.json`](./generated_export_sbom_not_provided.json) | A generated export with no SBOM, surfaced as a `Not provided` SBOM row rather than a blank cell. |

The records carry only opaque refs, controlled-vocabulary tokens, and reviewable
sentences — no raw artifact bytes, signatures, SBOM bodies, notice text, registry
URLs, license files, advisory payloads, private mirror endpoints, or customer
identifiers.
