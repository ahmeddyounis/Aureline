# Dense M5 Surface I18n Qualification

This fixture set is the dense-surface localization qualification for the claimed
localized M5 profiles (es-MX, ja-JP, ar-SA). It binds pseudolocalization,
text-expansion, RTL/bidi, font-fallback, IME composition, CJK, and localized
date/number proof to each claimed profile so a regression on a dense surface
narrows or blocks the profile claim automatically.

Surfaces covered: editor-adjacent panes, command palette, settings,
terminal/help, notebooks, data grids, pipeline/log views, docs/help panes,
guided tours, and support/report surfaces — dense workflows, not simple forms.

Files:

- `qualification.json` is the machine-readable qualification packet generated by
  `aureline-i18n`. It holds the surface inventory, harness cases, per-locale
  harness results, and the derived per-profile qualification gates.
- `review_export.json` is the exportable review packet QA, shiproom, and support
  ingest instead of re-running manual review sessions.
- `narrowing_cases.json` is the set of injected-regression scenarios that prove
  an IME, RTL/bidi, font-fallback, or localized-format failure blocks promotion
  on the claimed row, and a source-language fallback narrows it.

Regenerate and validate:

```sh
cargo run -q -p aureline-i18n --bin aureline_i18n_locale_pack_beta -- m5-dense-lab > fixtures/i18n/pseudoloc-rtl-ime-cjk/qualification.json
cargo run -q -p aureline-i18n --bin aureline_i18n_locale_pack_beta -- m5-dense-lab-review > fixtures/i18n/pseudoloc-rtl-ime-cjk/review_export.json
cargo run -q -p aureline-i18n --bin aureline_i18n_locale_pack_beta -- m5-dense-lab-narrowing > fixtures/i18n/pseudoloc-rtl-ime-cjk/narrowing_cases.json
cargo test -p aureline-i18n --test m5_dense_surface_i18n_lab --locked
```

The records carry no raw translated bodies — only stable ids, refs, result
states, and export-safe detail summaries.
