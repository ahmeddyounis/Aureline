# Attention And Lifecycle Vocabulary

This fixture set is the single governed terminology glossary for durable-attention
surfaces — the activity center, job-row badges, notification summaries,
lifecycle-state copy, and quiet-hours/admin suppression messaging — across the
claimed localized M5 profiles (es-MX, ja-JP, ar-SA). It exists so no surface
coins its own translated status wording: every surface that means the same thing
draws the same governed term, and severity, scope, and action order stay stable
across locales and truncation.

Files:

- `glossary.json` is the machine-readable glossary generated by `aureline-i18n`.
  Each term binds one durable-attention concept to a stable locale-neutral
  `term_key`, a locale-neutral severity rank and action-order index, one
  canonical source-language definition, and per-locale translations. The shell
  projection, support exports, and docs map localized attention states back to
  these keys.
- `parity_report.json` is the cross-locale audit. For every claimed locale it
  records whether severity rank, action order, lexical consistency, and severity
  under truncation hold, plus the text-expansion ceiling and the per-locale claim
  state. A drift makes the locale `blocked`; a source-language fallback makes it
  `narrowed`.
- `drift_scenarios.json` is the set of injected-mutation scenarios that prove a
  softened or strengthened severity, a reordered action, a broken lexical
  consistency, a term collision, or a severity hidden under truncation is caught
  before a profile can claim green.

Schemas: `schemas/i18n/attention-lifecycle-glossary.schema.json` and
`schemas/i18n/attention-localization-parity.schema.json`.

Regenerate and validate:

```sh
cargo run -q -p aureline-i18n --example dump_attention_vocabulary -- glossary > fixtures/i18n/activity-center-and-notifications/glossary.json
cargo run -q -p aureline-i18n --example dump_attention_vocabulary -- parity > fixtures/i18n/activity-center-and-notifications/parity_report.json
cargo run -q -p aureline-i18n --example dump_attention_vocabulary -- drift > fixtures/i18n/activity-center-and-notifications/drift_scenarios.json
cargo test -p aureline-i18n --test attention_vocabulary --locked
cargo run -q -p aureline-i18n --bin aureline_i18n_locale_pack_beta -- attention-vocab-validate
```

The records carry no raw provider payloads or credential bodies — only stable
term keys, locale-neutral severity ranks and order, localized labels, and
export-safe metrics.
