# M5 Project-Entry Components

This corpus exercises the reusable M5 project-entry component family frozen in
`artifacts/design/m5-project-entry-component-matrix.md`.

- `component_matrix.json` is the canonical fixture packet for the shared UI
  component schema.
- Every component row reuses the same target-kind, resulting-mode, trust,
  restore-fidelity, and blocked-vs-optional readiness vocabulary.
- Rows are redaction-safe and cite opaque evidence refs only; raw paths, raw
  repository URLs, credentials, support bundle bodies, and imported payloads do
  not appear here.
