# Rendered Preview Boundary Fixtures

These fixtures are valid, export-safe `rendered_preview_boundary_record` packets
that exercise the capability boundaries a docs rendered preview enforces. Each
one keeps every capability requested, cued, escapable, and non-privileged, keeps
a raw/source escape available, and keeps the rendered preview from ever
impersonating the native shell or a browser-owned control plane — the difference
is which mode is active and how each capability is qualified.

The canonical Split-mode boundary lives at
[`artifacts/docs/m5/rendered-preview-boundary-proof/support_export.json`](../../../../artifacts/docs/m5/rendered-preview-boundary-proof/support_export.json).
All files here are regenerated by the headless inspector:

```sh
cargo run -p aureline-docs --bin aureline_docs_rendered_preview_boundaries -- fixture <name>
```

## source_mode_local.json

A changelog previewed in **Source** mode from a local project pack. Nothing
renders, so `sanitization_state` is `not_applicable` and every capability is
`not_applicable`. Demonstrates that source mode keeps the raw Markdown canonical
and that no capability runs.

## rendered_mirrored_offline.json

A help article previewed in **Rendered** mode from a pinned offline pack.
Diagrams are `blocked` (the engine is unavailable offline), math is `disabled`,
and remote assets are `blocked` with `external_open_state` `unavailable` and no
open-externally action — because the source is offline. The source badge shows
`degraded_cached` freshness and `compatible_minor_drift`. Demonstrates honest
degradation to readable source when a capability cannot be provided safely, with
every degraded capability disclosing why.

## rendered_raw_html_disclosed.json

A module doc previewed in **Rendered** mode that opts into raw embedded HTML. The
`sanitization_state` is `raw_html_allowed_disclosed` and carries a
`sanitization_note`; custom components are `denied_by_policy` and `blocked` with a
disclosure note, while diagrams render under a `granted_sandboxed` posture and
remote assets stay blocked with an open-externally path. Demonstrates that raw
HTML renders only under an explicit disclosure and that a denied capability
degrades honestly to inert source text.

## rendered_degraded_accessibility.json

A README previewed in **Rendered** mode where zoom and reduced-motion parity
degrade honestly. `accessibility_parity` records `zoom_parity` and
`reduced_motion_parity` as `false` and carries a `parity_note` disclosing the
gap; keyboard parity stays `true` so the raw/source escape remains reachable.
Demonstrates that theme/zoom/density/motion parity is preserved where feasible
and disclosed when it cannot be.
