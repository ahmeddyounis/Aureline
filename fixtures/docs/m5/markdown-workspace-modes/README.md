# Markdown Authoring Workspace Mode Fixtures

These fixtures are valid, export-safe `markdown_authoring_workspace_record`
packets that exercise the source/split/rendered modes and the mirror/offline and
rendered-preview postures the canonical support export keeps green. Each one
keeps source identity, keyboard parity, and preview-safety disclosure intact —
the difference is which mode is active and how the rendered preview is qualified.

The canonical Split-mode workspace lives at
[`artifacts/docs/m5/markdown-workspace-proof/support_export.json`](../../../../artifacts/docs/m5/markdown-workspace-proof/support_export.json).
All files here are regenerated by the headless inspector:

```sh
cargo run -p aureline-docs --bin aureline_docs_markdown_workspace -- fixture <name>
```

## source_mode_local.json

A changelog edited in **Source** mode from a local project pack. Nothing renders,
so `sanitization_state` is `not_applicable` and every render capability is
`not_applicable`. Demonstrates that source mode keeps the raw Markdown canonical
and never renders content.

## rendered_mode_mirrored_offline.json

A help article previewed in **Rendered** mode from a pinned offline pack. The
source badge shows `degraded_cached` freshness and `compatible_minor_drift`, the
mirror state is `offline_pinned_pack`, and `browser_handoff_availability` is
`unavailable_offline` — so no `open_browser_action` is offered. Diagrams are
`blocked` and math is `disabled`. Demonstrates that mirror/offline state and a
narrowed handoff stay visible in the workspace rather than only in a secondary
inspector.

## rendered_raw_html_disclosed.json

A module doc previewed in **Rendered** mode that opts into raw embedded HTML. The
`sanitization_state` is `raw_html_allowed_disclosed` and carries a
`sanitization_note`; a custom component is `blocked` while diagrams render under a
`sandboxed_opt_in`. Demonstrates that raw HTML renders only under an explicit
disclosure and that custom components stay non-privileged.
