# History-surgery review fixtures

These fixtures are valid, export-safe `git_history_surgery_review_packet`
packets that each narrow the canonical sheets packet to a single risky verb,
exercising a decision path the canonical packet does not. Every sheet's decision
re-derives from its gate states, so the stored outcome can be verified against the
same gates every surface reads.

All three are generated by the conformance dump:

```bash
cargo run -p aureline-git --example dump_history_surgery_review_sheets -- force-push-protected
cargo run -p aureline-git --example dump_history_surgery_review_sheets -- rebase-raw-fallback
cargo run -p aureline-git --example dump_history_surgery_review_sheets -- provider-outage
```

## force_push_protected_blocked.json

A force-push whose target sits on a blocked protected branch. The decision is
`blocked` with reason `blocked_protected_branch`, yet the sheet still names its
exact lease ref and divergence class and keeps `local_truth_available_offline`
true — a blocked network mutation never hides the local preview/abort/restore
truth.

## rebase_raw_todo_fallback.json

A rebase whose structured todo parsing failed. The raw todo stays inspectable
(`raw_source_text_ref` is present) while `structured_cards_ref` is absent, so the
decision `downgraded`s to `downgraded_raw_inspection_only` rather than blocking —
the raw-todo fallback keeps the operation reviewable.

## reset_provider_outage_local_only.json

A reset whose provider overlay is unavailable and whose only recovery is a
reflog-only fallback. Both gates downgrade rather than block, so the decision is
`downgraded` and local truth stays available offline — a provider outage can never
block local preview, abort, or restore.
