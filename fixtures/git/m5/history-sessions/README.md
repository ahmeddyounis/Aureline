# History-surgery session fixtures

These fixtures are valid, export-safe `git_history_session_map` packets that each
narrow the canonical first-consumers map to one durable session, exercising a
guardrail the canonical map keeps green. Every binding re-derives from its
descriptor, so the same object drives every surface.

All three are generated by the conformance dump:

```bash
cargo run -p aureline-git --example dump_history_session_first_consumers -- stash
cargo run -p aureline-git --example dump_history_session_first_consumers -- publish-blocked
cargo run -p aureline-git --example dump_history_session_first_consumers -- conflict
```

## stash_distinct_verbs.json

A single stash/shelf entry. Apply, pop, drop, and create-branch stay distinct
verbs: every surface discloses all four, and only the mutation surfaces (desktop,
review, CLI/headless) mark them actionable.

## publish_blocked_invalidated.json

A publish/ref-update proposal whose approval is invalidated by new changes and
whose checks are invalidated. The network mutation stays gated on every surface —
no surface may publish until the proposal is refreshed.

## conflict_reopen_identity.json

A conflict session that preserves base/ours/theirs provenance and refs to both
the raw conflict text and its structured cards. Exact repo/worktree identity is
preserved on every surface, and support export and provider overlay never
hydrate the raw body.
