# M5 Repository-Topology and History-Surgery Matrix Fixtures

These fixtures are valid, export-safe matrix packets that exercise the narrowing
behavior the canonical support export keeps green. Each one keeps every topology
class, session object, degraded state, and risky operation present, with the
governance review, consumer parity, and freeze posture invariants satisfied — the
difference is which row narrows and why.

Both fixtures are generated by the conformance dump:

```bash
cargo run -p aureline-git --example dump_m5_git_topology_history_matrix -- submodule
cargo run -p aureline-git --example dump_m5_git_topology_history_matrix -- reset
```

## submodule_uninitialized_narrowed.json

The submodule topology row is narrowed to `mutation_denied` because the child
checkout is uninitialized. Mutation is blocked (`no_recovery_operation_blocked`)
and no preview is offered until the submodule is initialized — the parent claim
is narrowed, not hidden. Demonstrates the `uninitialized` and `dirty_child`
degraded states gating a child operation.

## reset_reflog_only_recovery.json

The `reset` risky operation falls back to `reflog_only_fallback_disclosed`
recovery because no checkpoint is possible. Recovery truth stays visible before
execution, demonstrating that a destructive operation discloses its reflog-only
fallback rather than proceeding silently.
