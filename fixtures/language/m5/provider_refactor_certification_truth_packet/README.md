# provider_refactor_certification_truth_packet fixture corpus

Fixture corpus for the stable provider-arbitration, diagnostic-convergence,
and refactor preview/rollback certification truth packet
(`schemas/language/provider_refactor_certification_truth.schema.json`).

Each fixture is a `ProviderRefactorCertificationTruthPacketInput` with an
`expect` block that pins the materialized packet's promotion state,
finding count, row count, and the lane, row-class, support-class,
provider-family, verdict, arbitration-proof, conflict, convergence-proof,
refactor-transaction, completeness, rollback-path, rollback-determinism,
generated-artifact-policy, evidence-drill, known-limit,
downgrade-automation, and evidence-class token sets, plus the
support-export safety verdict. Tests in
`crates/aureline-language/tests/provider_refactor_certification_truth_packet.rs`
load each case and assert that
`ProviderRefactorCertificationTruthPacket::materialize` agrees. The
corpus is regenerated by
`cargo run -p aureline-language --example dump_provider_refactor_certification_truth_packet`.

Cases:

- `baseline_stable.json` — Every claimed artifact-family lane (framework
  pack, notebook cell, generated source, structured artifact, and
  code-understanding graph) carries a `lane_certification` row at
  `certified` that names its acting provider family and a concrete
  verdict, plus one certification row per dimension: provider
  arbitration, diagnostic convergence, refactor preview, rollback
  determinism, and generated-artifact policy. The packet enumerates every
  required evidence drill and certifies stable.
- `certified_with_unbound_evidence_blocks_stable.json` — A
  `lane_certification` row claims `certified` while its evidence class is
  `evidence_unbound`; the packet emits `missing_evidence_class` plus
  `certified_with_unbound_binding` and blocks the stable claim instead of
  inheriting the adjacent certified rows.
- `missing_provider_arbitration_certification_blocks_stable.json` — A
  lane claims `certified` but drops its
  `provider_arbitration_certification` row; the packet emits
  `missing_provider_arbitration_coverage` so a lane cannot keep a
  certified grade without proving its arbitration truth.
- `missing_required_evidence_drill_blocks_stable.json` — The packet drops
  its only rollback-determinism drill; the packet emits
  `missing_required_evidence_drill` because a certified packet must carry
  the full evidence-drill set (fixture repo, notebook/generated/config
  cases, partial-scope, provider crash/quarantine, and rollback
  determinism).
- `mutating_refactor_without_labeled_preview_blocks_stable.json` — A
  `refactor_preview_certification` row certifies a mutating refactor with
  an `unsupported` completeness label; the packet emits
  `mutation_bypasses_preview_or_rollback` so transforms cannot certify
  behind an unlabeled or unsafe preview.
- `nondeterministic_rollback_blocks_stable.json` — A
  `rollback_determinism_certification` row on a certified lane binds a
  nondeterministic/unsafe rollback; the packet emits
  `rollback_determinism_not_proven`.
- `disagreement_collapsed_to_ranking_only_blocks_stable.json` — A
  `provider_arbitration_certification` row certifies provider
  disagreement but collapses it to ranking-only; the packet emits
  `disagreement_collapsed_to_ranking_only` so the losing provider and
  downgrade reason stay inspectable.
- `verdict_contradicts_certified_support_blocks_stable.json` — A
  `lane_certification` row claims `certified` support but binds a
  `blocked_pending_evidence` verdict; the packet emits
  `verdict_support_mismatch`.
- `dimension_bound_on_wrong_row_class_blocks_stable.json` — A
  `diagnostic_convergence_certification` row also binds an arbitration
  proof; the packet emits `arbitration_proof_not_permitted_on_row_class`
  so each certification dimension stays owned by exactly one row class.
- `narrowed_row_missing_disclosure_ref_blocks_stable.json` — A
  `lane_certification` row narrows to `certified_below` but drops its
  disclosure ref; the packet emits `narrowed_row_missing_disclosure_ref`
  (and, because the row still binds a non-`none` downgrade automation,
  `downgrade_automation_missing_disclosure_ref`).
- `raw_source_material_blocks_stable.json` — A row admits raw source
  bodies past the boundary; the packet emits `raw_source_material_present`
  because raw source bodies, refactor diffs, generated artifact bodies,
  notebook outputs, provider payloads, secrets, and ambient credentials
  must never leak through the certification boundary.
- `projection_collapses_arbitration_proof_vocabulary_blocks_stable.json`
  — The `compatibility_report` consumer projection collapses the
  arbitration-proof vocabulary; the packet emits
  `arbitration_proof_vocabulary_collapsed`, `consumer_projection_drift`,
  and `missing_consumer_projection`.
