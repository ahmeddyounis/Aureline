# M5 storage certification fixtures

- `packet.json`: canonical certification index for every claimed
  heavy-artifact family on every claimed M5 profile, binding the
  storage-class, clear-data, low-disk, pin/retention, corruption-repair, and
  export-before-delete proofs in one checked packet.
- `stale_pin_retention_gated.json`: degraded packet where the pin/retention
  audit is stale, so every protected family narrows to
  `protected_review_gated_only` and may only be touched through an explicit
  review.
- `blurred_cache_authority_blocked.json`: degraded packet where storage-class
  truth is stale and pressure behavior is hidden, so authoritative families
  block as `blocked_unverified` and disposable, pressure-evicted families
  narrow to `limited_class_scoped`.

Each fixture is regenerated by
`crates/aureline-support/examples/dump_m5_storage_certification_packet.rs` and
replayed against the seeded packet by
`crates/aureline-support/tests/m5_storage_certification.rs`.
